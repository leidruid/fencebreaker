# План разработки: fencebreaker (утверждён 2026-10-25)

Приложение для OpenWrt 25.12+ (apk, x86/64): несколько «тенантов»
маршрутизации, каждый направляет трафик выбранных сетей/хостов на выбранные
ресурсы через свой канал (интерфейс или VLESS/sing-box). Единый CoreDNS
обслуживает все тенанты (плагин fbtenant), обучает nft-наборы адресами из
DNS-ответов с зеркалом состояния и без повторных добавлений. Управление —
LuCI.

Решения: имя `fencebreaker`; таргет только 25.12+ (apk); перехват DNS 53 по
умолчанию (отключаем на тенант); списки ручные + URL-подписки; VLESS v1 —
TCP (TLS/REALITY); отказ канала — fallback/strict на тенант; v1 — IPv4,
архитектура под dual-stack; CoreDNS — один процесс; плагин синхронизирует
наборы с nftables и не добавляет уже добавленное.

Пакеты: `net/fencebreaker` (демон), `net/fencebreaker-coredns` (CoreDNS с
плагином fbtenant), `luci/luci-app-fencebreaker`. Зависимости: sing-box из
официального packages-feed, nftables.

Этапы: M0 каркас/CI → M1 интерфейсный тенант (nft+маршруты+geoip) →
M2 DNS-подсистема (плагин, hijack) → M3 VLESS → M4 подписки списков →
M5 LuCI → M6 стабилизация/e2e. ≈11–12 недель.

Подробные контракты компонентов — docs/CONTRACTS.md.

Дорожная карта после v1: IPv6, транспорты WS/gRPC/XHTTP, geosite,
kill-switch DoH, маршрутизация трафика роутера, DoT/DoH-upstream,
матрица архитектур (aarch64/armv7/...), локализация.
