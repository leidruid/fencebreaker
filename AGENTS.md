# AGENTS.md — правила проекта fencebreaker

## Публикация

- **Не публиковать проект нигде без явного разрешения пользователя**
  (git push, публикация gh-pages, релизы, загрузка на внешние сервисы,
  копирование за пределы этой машины).
- Публикация всегда согласовывается отдельно, в явном виде.
- CI-файлы в репозитории инертны, пока репозиторий не запушен; пушить
  нельзя без разрешения.

## Сборка

- Всё собирается локально (docker openwrt/sdk, локальные go-модули);
  внешние действия — только скачивание исходников/образов, не загрузка.
